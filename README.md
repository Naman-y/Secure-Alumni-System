# Secure Alumni System

A secure web-based alumni management system developed as part of  
**CSE-313: Foundations of Cyber Security**.

## Features
- Secure login and registration
- Password encryption
- Role-based access
- Secure APIs
- Environment variables protection

## Tech Stack
- Node.js
- Express.js
- MongoDB
- HTML, CSS, JavaScript

## Security
- Password hashing
- JWT authentication
- Environment variables (.env)

## Setup
1. npm install
2. create .env file
3. npm start

## Note
.env file is not pushed to GitHub for security reasons.
